Projeto de Estruturas de Dados · Bahia 2023–2025

Mortes violentas na Bahia, em números

Esta página usa um programa escrito em C para ler a planilha de ocorrências, filtrar os dados e guardá-los em diferentes estruturas (pilha, fila, listas…). Mexa nos filtros e veja os gráficos — e também quanto tempo o programa levou em cada etapa.

Cada linha da planilha é o total de vítimas de um município em um mês. Por trás de cada número existe uma pessoa e uma família: use os dados para entender o problema, não para estigmatizar lugares.
